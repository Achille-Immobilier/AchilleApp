Outils AchilleApp

Boutons à glisser dans la barre de favoris de Chrome (Ctrl + Maj + B pour l'afficher). Ils remplacent les anciens liens.

1. Importer une annonce dans l'AchilleApp

Sur une annonce (SeLoger, Bien'ici, Leboncoin…), cliquez : l'annonce s'ouvre pré-remplie dans l'AchilleApp, à la nouvelle adresse.

➜ Importer dans AchilleApp

2. Rechercher le descriptif sur FIPAC

Inchangé, fourni ici pour tout avoir au même endroit.

➜ Chercher sur FIPAC

Installation

  1. Supprimez l'ancien favori « Importer » (clic droit → Supprimer).
  2. Glissez le bouton vert ci-dessus dans la barre de favoris.
  3. Testez sur une annonce : l'AchilleApp doit s'ouvrir sur achilleapp.pages.dev.
Les boutons ne font rien sur cette page : ils agissent sur la page d'une annonce.
