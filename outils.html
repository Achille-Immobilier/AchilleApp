Outils AchilleApp

Boutons à glisser dans la barre de favoris de Chrome (Ctrl + Maj + B pour l'afficher). Ils remplacent les anciens liens.

1. Importer une annonce dans l'AchilleApp

Sur une annonce (SeLoger, Bien'ici, Leboncoin…), cliquez : l'annonce s'ouvre pré-remplie dans l'AchilleApp, à la nouvelle adresse.

➜ Importer dans AchilleApp

2. Rechercher le descriptif sur FIPAC

Sur une annonce, cliquez : le bouton lit le descriptif, garde ses mots distinctifs (et la surface Carrez si elle est écrite avec une décimale) et les cherche dans vos fiches Fipac. Une sélection à la souris reste prioritaire.
Version du 04/11/2026 : corrige SeLoger (le bouton prenait du code de mise en page pour le descriptif) ; remplacez l’ancien favori « ? Fipac ».

➜ Chercher sur FIPAC

Installation

  1. Supprimez les anciens favoris « Importer » et « ? Fipac » (clic droit → Supprimer).
  2. Glissez les deux boutons ci-dessus dans la barre de favoris.
  3. Testez sur une annonce : l'AchilleApp doit s'ouvrir sur achilleapp.pages.dev.
Les boutons ne font rien sur cette page : ils agissent sur la page d'une annonce.
